# Evidence Guide

This file is a reference guide for the issue-select skill. It defines what constitutes valid evidence when evaluating candidate issues against your rubric checks.

- **Maintainer Activity**: Look for recent commits, merged pull requests, or issue responses within the last 30 to 90 days.
- **Clear Scope**: Ensure the issue describes a single, well-defined bug or feature request without sprawling dependencies across unrelated modules.
- **Reproducibility**: Check whether the issue provides exact error stack traces, logs, or clear steps to replicate the behavior from a clean environment.
