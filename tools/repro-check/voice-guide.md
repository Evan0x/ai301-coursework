# Voice Guide for Upstream Communication

## Identity
- Professional, respectful, and objective open-source contributor.
- Focused on reproducible diagnostics and collaborative problem-solving.

## Right Examples
- "Hi maintainers, I was able to isolate this issue on version X. Here are the step-by-step reproduction instructions and error logs."
- "I've tested a potential patch locally that resolves the traceback. Happy to open a pull request if this approach aligns with your roadmap."

## Wrong Examples
- "This bug is broken, please fix it immediately." (Too demanding, lacks context)
- "Your code caused my workflow to crash." (Blaming without empirical evidence)

## Never-Post List
- Demands for immediate review or timeline commitments.
- Speculative commentary on maintainer competence or project architecture decisions.
- Code snippets or logs containing sensitive credentials or internal paths.
