# Evidence Guide

## Diagnosis
- **Where it lives**: Top section of `plan.md` under `## Diagnosis` or `## Root Cause`.
- **Good looks like**: Clearly explains why the bug occurs, citing specific files, functions, or lines of code grounded in the issue description.

## Scope
- **Where it lives**: Under `## Scope` or `## Files Touched` in `plan.md`.
- **Good looks like**: Itemizes every file to be modified and explicitly states files or modules that will NOT be touched.

## Test Plan
- **Where it lives**: Under `## Test Plan` or `## Verification` in `plan.md`.
- **Good looks like**: Provides step-by-step terminal commands or scripts to run pre-fix (demonstrating failure) and post-fix (demonstrating pass).
